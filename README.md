# 교육학 연구 지원 에이전트

연구 아이디어를 계획서로 구체화하고 필요에 따라 문헌검색과 PDF 내용 추출을 연결하는 프롬프트형 에이전트입니다. 특정 교과에 제한되지 않으며 특성화고 전기 실습의 AI 보조 연구를 예시로 제공합니다.

## 구성
| 파일 | 역할 |
|---|---|
| AGENTS.md | 팀장, 공통 원칙, 인계 검사와 반복 검토 |
| RESEARCH_PLAN_AGENT.md | 연구계획서 진단·작성·수정 |
| LITERATURE_SEARCH_AGENT.md | 문헌검색·원출처 검증·공개 PDF 확보 |
| PDF_PARSER_AGENT.md | PDF 추출과 원본 대조 지침 |
| examples/scenarios.md | 가상 입력과 기대 행동 |
| .gitignore | 공개 파일 허용 목록 |

## 사용
저장소를 내려받아 Codex 등 지침과 파일을 읽는 AI 작업 환경에서 프로젝트 폴더로 엽니다. AGENTS.md를 읽고 아래처럼 요청합니다. GitHub에 올리는 것만으로 웹에서 에이전트가 실행되지는 않습니다.

### 계획서 작성
> 특성화고 1학년 전기 실습에서 AI가 회로 오류 점검 힌트를 제공하는 연구를 계획하고 싶어. 필요한 질문을 하고 예비 연구계획서를 작성해줘. 검색과 PDF 처리는 아직 하지 마.

### 문헌검색
> work/전기실습/proposal.md를 읽고 인계 검사를 해줘. 검색 가능한 상태라면 필요한 핵심 문헌과 공식 공개 PDF를 확보하고 미확인 근거를 구분해줘.

### PDF 추출
> 앞서 검증한 PDF를 원본 페이지 번호가 있는 Markdown으로 추출하고 원본과 비교해줘. 표·수식의 문제와 검토하지 못한 범위를 보고해줘.

### 수정
> 지정한 계획서의 연구문제를 학습 효과에서 오류 해결 과정 탐색으로 바꿔줘. 자료수집과 분석도 함께 수정해줘.

경로는 실제 연구 폴더에 맞춰 지정합니다. 인원·기간·실습 조건은 제공되거나 확인된 정보만 사용합니다.

## 실행 조건과 한계
- 파일 작업이 가능한 AI 환경이 필요합니다. 하위 에이전트 기능이 없으면 같은 대화에서 역할을 순차 수행합니다.
- 검색은 실제 웹·학술 검색 도구가 필요합니다. 인증은 사용자 환경에서 준비하며 비밀키를 저장소에 넣지 않습니다.
- PDF 추출·렌더링 도구가 필요하고 이미지 문서는 OCR 도구가 추가로 필요할 수 있습니다. 독립 PDF 실행 프로그램이나 OCR 모델은 포함하지 않습니다.
- 자동 수정은 최대 두 차례이며 해결되지 않은 정보·도구 부족을 보고합니다. 지침은 정확성·학술적 타당성·기관 승인을 보장하지 않습니다.
- 전기 실습의 작업 안전과 통전 승인은 담당 교사가 확인하도록 설계합니다.

## 산출물과 공개 범위
연구 산출물은 work/<연구명>/ 아래 proposal.md, review.md, handoff.md 및 literature/, parsed/에 저장합니다.
공개 대상은 지침·사용법·가상 점검 예시·설정입니다. 교재, 학생 정보, 연구계획서 산출물, 논문 원문·추출문, 키와 로그는 공개하지 않습니다. .gitignore는 이미 추적하는 파일이나 파일 안의 민감정보까지 제거하지 않으므로 실제 커밋 내용을 확인해야 합니다.

## 검증 범위
[실제 실행 검증 기록](VALIDATION.md)에 관찰된 결과·발견 오류·수정·미검증을 정리했습니다. 계획서 작성과 수정, 인계 조건, 합성 PDF의 추출 및 실패 처리, 공개 논문 한 편의 파일 확보를 실제 시험했습니다. 실행한 하위 에이전트 시험과 주 에이전트 역할 전환을 구분했습니다.
추가 독립 회귀시험은 사용량 제한으로 미완료입니다. OCR 정확도, 강제 중단·재개, 전체 종단간 흐름과 반복 신뢰도는 검증하지 않았습니다. 모든 환경에서 충분히 검증됐다고 주장하지 않습니다.
